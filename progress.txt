Session 4-E — Creative fatigue predictor  [ DONE 2026-04-23 ]
-------------------------------------------------------------
Bayesian CTR forecast over the rolling 7-day ad_fatigue history. Flags ads
that are on track to drop ≥30% from peak CTR within the next 3 days, before
the reactive detector in lib/ad-fatigue-tracker.js actually trips. Lets the
operator rotate creatives *proactively* instead of waiting for the cliff.

Model (lib/creative-fatigue-predictor.js):
  y_i = log(ctr_i + ε), weights w_i = sqrt(impressions_i + 1)
  Weighted OLS → residual variance σ² (unbiased, k=2).
  Prior on slope β ~ N(0, τ²)  τ = PRIOR_SLOPE_STD = 0.3.
  Posterior β: mean = (Sxy/σ²) / (1/τ² + Sxx/σ²), std = 1/√posterior_precision.
  Intercept recomputed with shrunken slope (weighted-mean identity).
  Forecast y_hat at day n-1+3; predictive std combines residual + slope.
  P(fatigue) = Φ((log(peak·0.7 + ε) - y_hat) / stdForecast).
  Trend labels from slope: sharp_decline ≤ -0.20, declining ≤ -0.05,
                             stable ∈ (-0.05, 0.05), growing ≥ 0.05.
  At-risk cutoff: P(fatigue) ≥ 0.6 AND not already reactively fatigued.

Session 4-G — Bridge version check  [ DONE 2026-04-23 ]
-------------------------------------------------------
Detects stuck Shopify theme caches. Every browser payload that the bridge
sends now carries a `bridge_version` constant (see assets/calqix-meta-bridge.js
top-of-file). The server fans that field into Redis via a tiny tracker, and
a 30-minute cron flags older versions that keep reporting in *after* a newer
version has gone live — the telltale sign of a CDN or browser cache that
didn't purge.

      else in the code had to change. captureIdentity() also attaches it.
      window.calqixMeta.BRIDGE_VERSION exposes it for console/dashboard use.

      sanitizeVersion() / recordVersion() / getVersionStats(). Redis:
        bridge:version:count:{v}:{hour}   TTL 72h  (hourly counter)
        bridge:version:first_seen:{v}     TTL 30d  (age anchor)
        bridge:version:last_seen:{v}      TTL 30d
