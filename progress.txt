Operational notes
-----------------
- Shopify's GitHub sync auto-pushes theme asset changes as
  "Update from Shopify for theme Themex-Calqix/main" commits.
  Pull --rebase before pushing theme-related commits.
- Custom Pixel code (shopify-custom-pixel.for-admin.js) has to be
  pasted manually into Shopify Admin > Customer events; no API exists.
- progress.txt is the single source of truth across sessions.
